くるりえ

プライバシーポリシー

最終更新日：2026年9月11日

パズルゲーム「くるりえ」（以下「本アプリ」）は、独自のサーバーを持たず、利用者の個人情報を集めることも、第三者へ販売・提供することもありません。遊んだ記録は端末の中に保存します。オンラインランキングを使うときにかぎり、Apple の Game Center へ得点と難易度を送ります。

1. 端末の中に保存する情報

ゲームを続けて遊べるようにするため、次の情報をお使いの端末の中だけに保存します（iOS の標準的な保存領域を使います）。いずれも個人を特定できる情報ではなく、外部へ送信することも、作者が見ることもありません。

  • モード・難易度ごとの最高点
  • プレイ履歴（日時・モード・難易度・得点・クリアしたステージ数）
  • 難易度の設定、効果音・BGM の ON／OFF
  • 中断したゲームの途中経過

本アプリを端末から削除すると、上記のすべてが消去されます。消えた記録を元に戻すことはできません。

2. Game Center へ送る情報

オンラインランキングには、Apple の Game Center を利用します。Game Center にサインインした状態で「じっくり」「2分アタック」を遊び終えたとき、またはランキング画面で「更新する」を押して過去の記録を送り直したときに、次の情報が Apple のサーバーへ送られます。

  • 得点（モードごとのランキングに載る点）
  • その得点を取ったときの難易度（やさしい／ふつう／むずかしいの区別を表す数値）

これらは、Apple が管理するプレイヤー識別子に紐づいて記録されます。ランキングに並ぶ名前は Game Center のニックネームで、本アプリは独自のニックネームを持たず、利用者の名前を預かることもありません。「練習」モードは記録を取らないため、何も送信しません。Game Center にサインインしていない場合も、何も送信しません。

送信された情報は Apple のプライバシーポリシー（https://www.apple.com/legal/privacy/ja/）に従って取り扱われ、作者のもとに集まることはありません。サインアウトや利用の制限は、iOS の「設定」＞「Game Center」および「スクリーンタイム」から行えます。

3. 集めない情報

本アプリは次のいずれも取得しません。年齢や生年月日を尋ねることもありません。

  • 氏名、住所、電話番号、メールアドレスなどの連絡先
  • 位置情報
  • カメラ、マイク、写真、連絡先、カレンダーなどの端末データ
  • 広告の表示、広告識別子（IDFA）を用いたトラッキング、アプリ内課金
  • アクセス解析・行動ログ（アナリティクスや他社のトラッキング SDK を組み込んでいません）

また、作者が運営するサーバーやデータベースを一切持ちません。上記の Game Center への送信を除き、本アプリが外部と通信することはありません。本アプリはオープンソースの部品を利用していますが、いずれも端末内の処理に使うもので、外部へ情報を送るものではありません。

4. このポリシーの変更

本ポリシーは、法令の変更や本アプリの機能追加にあわせて改定することがあります。重要な変更があった場合は、このページの最終更新日を改めます。
